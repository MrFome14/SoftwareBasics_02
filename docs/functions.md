# circle

<a id="circle.area"></a>

#### area

```python
def area(r)
```

Вычисляет площадь круга.

Параметры:
    r (int/float): радиус круга.

Возвращаемое значение:
    float: площадь круга.

Пример вызова:
    area(5)
    Результат: 78.53981633974483

<a id="circle.perimeter"></a>

#### perimeter

```python
def perimeter(r)
```

Вычисляет длину окружности.

Параметры:
    r (int/float): радиус круга.

Возвращаемое значение:
    float: длина окружности.

Пример вызова:
    perimeter(5)
    Результат: 31.41592653589793

<a id="triangle"></a>

# triangle

<a id="triangle.area"></a>

#### area

```python
def area(a, h)
```

Вычисляет площадь треугольника по основанию и высоте.

Параметры:
    a (int/float): длина основания треугольника.
    h (int/float): высота, проведённая к основанию.

Возвращаемое значение:
    int/float: площадь треугольника.

Пример вызова:
    area(6, 4)
    Результат: 12.0

<a id="triangle.perimeter"></a>

#### perimeter

```python
def perimeter(a, b, c)
```

Вычисляет периметр треугольника по трём сторонам.

Параметры:
    a (int/float): длина первой стороны.
    b (int/float): длина второй стороны.
    c (int/float): длина третьей стороны.

Возвращаемое значение:
    int/float: периметр треугольника.

Пример вызова:
    perimeter(3, 4, 5)
    Результат: 12
