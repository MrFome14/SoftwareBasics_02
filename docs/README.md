## 1. Документирование функций в исходном коде

В исходных файлах проекта добавлены описания каждой функции. Для каждой функции указывается её назначение, входные параметры и возвращаемое значение в соответствии с шаблоном.

### 1.1. Файл **circle.py**

Файл содержит функции для вычисления площади круга и длины окружности.

**Функция area(r)**

* **Назначение:** вычисление площади круга.
* **Параметр:** **r** — радиус круга.
* **Возвращаемое значение:** площадь круга, вычисленная по формуле \(S = \pi r^2\).
* **Пример вызова:**

  ```python
  area(5) # Результат: 78.53981633974483
  ```

**Функция perimeter(r)**

* **Назначение:** вычисление длины окружности.
* **Параметр:** **r** — радиус круга.
* **Возвращаемое значение:** длина окружности, вычисленная по формуле \(P = 2\pi r\).
* **Пример вызова:**

  ```python
  perimeter(5) # Результат: 31.41592653589793
  ```

### 1.2. Файл **rectangle.py**

Файл содержит функции для вычисления площади и периметра прямоугольника.

**Функция area(a, b)**

* **Назначение:** вычисление площади прямоугольника.
* **Параметры:** **a**, **b** — длины сторон прямоугольника.
* **Возвращаемое значение:** площадь прямоугольника по формуле \(S = ab\).
* **Пример вызова:**

  ```python
  area(4, 6) # Результат: 24
  ```

**Функция perimeter(a, b)**

* **Назначение:** вычисление периметра прямоугольника.
* **Параметры:** **a**, **b** — длины сторон прямоугольника.
* **Возвращаемое значение:** периметр прямоугольника по формуле \(P = 2(a+b)\).
* **Пример вызова:**

  ```python
  perimeter(4, 6) # Результат: 20
  ```

### 1.3. Файл **square.py**

Файл содержит функции для вычисления площади и периметра квадрата.

**Функция area(a)**

* **Назначение:** вычисление площади квадрата.
* **Параметр:** **a** — длина стороны квадрата.
* **Возвращаемое значение:** площадь квадрата по формуле \(S = a^2\).
* **Пример вызова:**

  ```python
  area(5) # Результат: 25
  ```

**Функция perimeter(a)**

* **Назначение:** вычисление периметра квадрата.
* **Параметр:** **a** — длина стороны квадрата.
* **Возвращаемое значение:** периметр квадрата по формуле \(P = 4a\).
* **Пример вызова:**

  ```python
  perimeter(5) # Результат: 20
  ```

### 1.4. Файл **triangle.py**

Файл содержит функции для вычисления площади и периметра треугольника.

**Функция area(a, h)**

* **Назначение:** вычисление площади треугольника по основанию и высоте.
* **Параметры:** **a** — длина основания, **h** — высота, проведённая к основанию.
* **Возвращаемое значение:** площадь треугольника по формуле \(S = \frac{ah}{2}\).
* **Пример вызова:**

  ```python
  area(6, 4) # Результат: 12.0
  ```

**Функция perimeter(a, b, c)**

* **Назначение:** вычисление периметра треугольника.
* **Параметры:** **a**, **b**, **c** — длины сторон треугольника.
* **Возвращаемое значение:** периметр треугольника по формуле \(P = a+b+c\).
* **Пример вызова:**

  ```python
  perimeter(3, 4, 5) # Результат: 12
  ```
